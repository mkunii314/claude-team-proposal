01

Claude × 業務効率化でできることの観点

Claude による業務効率化には、大きく次の 2 つの軸があります。

A ・ Claude で作る

Claude による開発で、効率化ツール・アプリを作る

Claude Code で業務を効率化するツールやアプリを開発します。一度作れば、誰でも繰り返し使える仕組みとして残ります。

例：定型作業の自動化スクリプト、社内向け Web ツール、データ集計・変換ツール

B ・ Claude にやらせる

Claude に直接、ファイル編集・調査・作成をさせる

ツールを作らず、その場の作業を Claude に任せます。人は指示と確認に集中できます。

例：SharePoint を横断したファイル調査・要約、ドキュメントのチェック（誤記・記載漏れ・整合性）、資料・Excel の作成や修正、議事録・提案書の下書き

私がやりたいこととして挙げるのは A 軸が主です。B 軸の作業は、基本的に Claude のアカウントを付与された人しか行えません。そのため B 軸では作業そのものよりも、B 軸でできること、できたことその結果を社内に共有し、Claude で何ができるかを広めることを目的に行います。

03

体制

体制はそもそもの部分から L 会で検討を進めていきたいですが、私の考えは下記の通りです。

社員から 3 名を募り、業務効率化チームを特設チームとして立ち上げ。

■ 体制の期間

1 年間特設チームで動き、実績やその後の内容が問題なければ社内業務化。
※Claude が年契約想定のため、期間は 1 年

■ 課題の吸い上げ

社内全体や各会議体、事業部から：アンケート、口頭聞き取りを行う。
また、常設の要望窓口（Teams のチャネルなど）を開き課題を集める。

■ 報告

業務会または Teams 上で、A 軸の成果または B 軸の共有を行う。
